# 活动日程

学生从「活动日程」查找服务时段，负责人从「管理日程」进入自己管理的活动，审核员从「全院日程」进入待审修订。列表和时间轴共用一次查询，日程上只选段和跳转，改期在活动编辑页办理，审批在审核页办理。

## 谁能看到哪些安排

四种范围共用 `GET /api/v1/timeline`。服务端在每次读取时重新判断权限与报名关系。[接口契约](../packages/contracts/openapi_v1.2.5.yaml) · [日程查询](../apps/api/src/timeline/timeline.ts)

| 范围 | 活动与展示版本 |
| --- | --- |
| 公开 `public` | 默认显示已发布活动，只展示获批版本。活动发现页的服务日期筛选也按获批安排判断。 |
| 本人 `mine` | 只展示本人已录取活动的获批安排。退出待处理期间仍可见，退出获批移出，恢复录取后重现。仅此范围提示计划时段重叠。 |
| 本人管理 `managed` | 限当前活动成员关系，默认工作版本，可切换获批版本。移出单项活动后，刷新会从列表、时间轴和当前详情移除该活动，保留其他可见活动。 |
| 全院 `all` | 按后台授权读取，展示版本同管理日程。两个管理范围的审核状态筛选均看当前工作版本，负责人候选取自授权范围，独立于筛选、窗口和当前页。 |

公开与本人日程省略 `has_pending_review`、`current_review_id`。在这两个范围请求工作稿或按审核状态、负责人筛选会收到 403。各范围的「进行中」按获批安排判断，管理端可同时看到工作版本的时段和待审标记。

## 时间窗口与分段

小时、日、周、月刻度都查询带时区的半开窗口 `[from, to)`，最长 31 日。按北京时间展开每周规则，排除日移除当日全部例行时段，补充时段单独计入。时段开始早于窗口结束、结束晚于窗口开始即相交，返回完整起止时刻。例如前晚 23:00 至当日 02:00 的服务在两天都能选中。[时间窗口](../packages/ui/src/timeline/window.ts) · [甘特图交互](../DESIGN.md#甘特图交互)

## 分页与刷新

服务端先限定可见范围和筛选，再在可重复读事务内按活动编号、ID 升序计数和取页。`total` 是活动数，每项带齐窗口内的分段，空页也返回本页的 `state_evaluated_at`。响应头 `X-Timeline-Range` 是全部匹配项的摘要，涵盖活动身份、版本、安排、地点、负责人和展示状态。本人范围另计用于判断重叠的计划时段，请求时刻本身不计入摘要。[活动读取](../apps/api/src/activities/list.ts) · [前端分页](../packages/ui/src/timeline/scheduleRange.ts)

| 页面动作 | 读取与提交规则 |
| --- | --- |
| 首次进入或切换条件 | 从第 1 页读取，每页 20 项。范围、版本、窗口、筛选或页大小变化时立即撤下旧行与详情，旧查询停止领取新页，迟到响应作废。 |
| 加载更多 | 先读下一页。合并前核对摘要、总数、连续页号、页大小、应有行数、活动排序，以及每行与所在页的评估时刻。范围收缩时裁掉多余页。 |
| 摘要或页结构变化 | 从首页重读目标范围，整轮通过校验后才替换结果。连续两次不一致，保留上次已核验结果并提示重试。服务端未提供摘要时整段重读，仅能校验页结构。 |
| 定时刷新或重试 | 页面可见时每 60 秒刷新，聚焦或恢复可见立即刷新。各轮串行，每轮按页号升序领取，最多 3 个请求在途。读取期间收到的刷新合并为一次。普通错误记录最小失败页并保留已有结果，重试从首页重读到目标页。当前查询任一页返回 403 时清空数据与详情，提示权限收回。 |

## 选段与审核返回

URL 中的 `item` 是活动 ID，`slot` 是由活动 ID、展示版本和开始时刻组成的 `occurrence_key`。只有 `item` 时选该活动的首段。活动尚未加载时逐页补读，找到活动或读完即停。所选段开始于窗口结束及以后可提前停止，开始于窗口之前仍需查找跨午夜段。[日程页](../packages/ui/src/timeline/SchedulePage.vue)

成功读取后按下表顺序判定。失效时清除选段并关闭详情。范围或展示版本切换时直接清除选段，窗口与筛选变化则在新结果中重新定位。

| 最新结果 | 页面反馈 |
| --- | --- |
| 匹配到所选时段键，或仅有活动 ID 且找到首段 | 保留选中，用最新数据更新详情。 |
| 键未匹配且键中开始时刻落在窗口外 | 所选时段已移出当前窗口 |
| 活动已不在结果里，或该活动没有可选分段 | 所选活动已移出当前筛选。 |
| 活动仍在，窗口内的所选键已消失 | 所选时段已随安排更新失效，已回到日程。 |

从待审时段进入审核页，批准或驳回后返回原日程 URL，保留窗口、刻度、视图及筛选并重读。批准后学生刷新可见新安排，驳回后仍见原获批安排。原选段按同一键重新定位，「只看待审核」会移出已处理活动。[审核页](../apps/admin/src/activities/ReviewPage.vue)

## 回归用例

接口用例覆盖四种范围、管理字段、版本、31 日边界、周期例外、分页和重叠提示。招募接口用例从真实退出与恢复审批检查本人日程。下表中的交接场景通过独立测试库变更成员关系，验收的是日程刷新后的可见范围。[日程接口用例](../apps/api/test/timeline.test.mjs) · [招募接口用例](../apps/api/test/recruitment.test.mjs) · [页面用例](../apps/api/test/pages.test.mjs) · [运行命令](../README.md#开发检查)

| 用例编号 | 需求 | 页面用例标题 |
| --- | --- | --- |
| 日程 1-1 | F3 审核返回 | 审核改期后返回原日程保留条件并重读 |
| 日程 1-2 | F4 报名与交接 | 报名与交接改变可见范围 |
| 日程 1-3 | F5 跨页边界 | 分页期间数据变化后重校准 |
| 日程 1-4 | F6 请求上限 | 深分页刷新请求上限 |
| 日程 1-5 | F6 补页与重试 | 日程分页可重试，详情返回只补读到所选页，候选跨页可用 |
| 日程 1-6 | F6 切换后重试 | 切换筛选时重新聚焦并读取失败，重试仍只显示新条件的结果 |
| 日程 1-7 | F1 范围与版本、F7 条件切换 | 切换展示版本不展示旧稿，权限收回时清空数据和详情 |

| 日程 1-10 | F2 分段绘制 | 时间轴按真实安排绘制分段，当前线取自服务端时刻 |

| 日程 1-15 | F11 整段重试 | 刷新重试整段重读不拼接旧页 |

跨页用例用 41 项活动比较列表、时间轴与服务端的标题顺序、总数和首行首段键，样本标题唯一。深分页用例加载 1,001 项共 51 页，记录请求页序与在途峰值。并发失权用例在两页分别注入 503 和 403，验证权限提示优先。
