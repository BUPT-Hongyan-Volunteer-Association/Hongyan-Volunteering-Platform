# 集成用例索引（RTM）

一节一个业务故事，一行一条集成用例。本索引登记该业务故事已立项的集成用例：状态为「保留」的行对应盘上已存在的用例，状态为「新增」的行在实施轮按编号落成。业务故事尚未建立索引的，记在文末债务表，不假装完整。

## 使用约定

- 编号形如 `<业务故事> <节号>-<行号>`（如 `日程 1-1`）。新增用例的测试标题写成 `t.test('<编号> <标题>')`，编号与索引逐字一致，与既有用例同在 `apps/api/test/pages.test.mjs` 的顶层用例内。
- 保留用例的标题与断言不改，编号只在本索引内引用；标题按现状原样登记。
- 「业务入口」写用户从哪个页面、哪个动作进入这条业务结果。
- 「状态」：新增 = 本批加入；保留 = 既有用例，本批不改标题与断言。
